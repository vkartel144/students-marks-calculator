Deployment Guide (GitHub & Vercel)

This single-file web application can be deployed instantly for free on either GitHub Pages or Vercel with zero configuration required!

1. Deploying on GitHub Pages

  1. Create a new public repository on GitHub.
  2. Upload or commit this file as index.html.
  3. Go to repository Settings > Pages.
  4. Under Build and deployment, set branch to main and folder to / (root).
  5. Save and your URL will be generated automatically!

2. Deploying on Vercel

  1. Go to Vercel Dashboard and log in with GitHub.
  2. Click Add New... > Project and import your repository.
  3. Leave framework preset as Other (since it's pure HTML/JS).
  4. Click Deploy to get a live global deployment link instantly.
